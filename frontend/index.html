Supported image formats: JPEG, PNG, GIF, and WebP.

When the image is sent: Choosing Send image for file identity marks the selected file to upload when you later click Check now (after investigation consent and sign-in). Nothing leaves this device until you confirm send and then check the claim.

What is uploaded: The original file (JPEG, PNG, GIF, or WebP) goes to the RealityCheck AI server. Those bytes are retained until the account is deleted (or the image is removed in a deletion flow). Image bytes are not sent to the assessment model.

File identity: The server calculates a SHA-256 of the received bytes. That hash identifies the file. It does not prove authenticity or that the pictured event is true.

If you decline metadata consent: Declining does not strip embedded EXIF (including GPS and camera details) from the uploaded original. The server will not read those camera, date, and location fields for analysis, but the embedded data may still remain inside the stored file.

Before you check: RealityCheck AI will store your claim and any retrieved sources in your account. One investigation may call OpenAI for claim extraction and assessment, and Parallel for search (and page extraction when you submit a URL). Automated results are not proof of truth. Avoid submitting sensitive personal information about others without authority or consent.

Provider usage: extraction, search, and assessment calls may each run once for a typical claim check. This product does not display dollar amounts because exact billing figures are not available from the providers in this app.

How a check is assessed

RealityCheck uses six official assessment outcomes. It does not claim certainty it does not have, and live results stay conservative when support is not confirmed.

All six names belong to the official assessment vocabulary. In the current build, Verified and Partially verified are not confirmed by the live evidence checks—when support is not established, the result is Unresolved. Insufficient evidence and Unresolved are currently supported. Contradicted and Potential manipulation appear only when strict literal conditions in stored source text are met.

Verified
Defined when strong, confirmed support is established. Not confirmed by the current live checks.
Partially verified
Defined when only some parts are confirmed. Not confirmed by the current live checks.
Contradicted
A cited stored sentence is a direct literal negation of the claim. Requires that strict condition.
Insufficient evidence
There is not enough stored evidence to reach a conclusion. Currently supported in live checks.
Unresolved
Support could not be confirmed, or available evidence conflicts. Currently supported in live checks.
Potential manipulation
A cited stored sentence names the sealed file and states fabrication. Requires that strict condition.

RealityCheck AI does not guarantee truth. Assessments depend on available evidence and source coverage. Insufficient evidence and unresolved outcomes are valid. Always review cited sources. File identity and Content Credentials do not prove that a depicted event happened. See the Pilot Privacy Notice.
